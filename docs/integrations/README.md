# Integrácie — rozcestník

Externé služby a asistenti, s ktorými tréner pracuje. Jediná externá služba s dátami je
Garmin Connect; asistenti bežia lokálne a k dátam pristupujú cez MCP server projektu
([rozhrania](../coach/interfaces.md)).

| Stránka | Čo tu nájdeš |
| --- | --- |
| [Garmin Connect](garmin-connect.md) | Účet, synchronizácia hodiniek, prihlásenie knižnicou, token, limity a blokácie, čo robiť pri výpadku. |
| [Asistenti](assistants.md) | Claude Code a Codex: čo čítajú, ako sa registruje MCP, spoločné pravidlá správania trénera. |
