# Aplikácia — rozcestník

Lokálna aplikácia, ktorú na Windows vytvorí `install.cmd` vedľa stiahnutého repozitára,
uv, spravovaný Python, venv so závislosťami, výber
dátového adresára, skratka na ploche, registrácia MCP v asistentoch. Všetko je k 15. 10. 2026
návrh; inštalátor neexistuje. Ako repozitár stiahnem, vlastní [`HOW_TO_USE.md`](../../HOW_TO_USE.md);
jednoduchý postup je v [používaní](../usage/new-computer.md).

| Stránka | Čo tu nájdeš |
| --- | --- |
| [Členenie](layout.md) | Dva susedné adresáre, strom `runtime/config/logs/sprava/scripts`, komponenty, čo sa zachováva. |
| [Inštalácia](installation.md) | Predpoklady, `install.cmd`, čo inštalátor v akom poradí urobí a overí, výstupy a kódy. |
| [Aktualizácia a odinštalovanie](update-and-uninstall.md) | `git pull` + inštalácia, reset runtime, odinštalovanie, čo ostáva. |
| [Externé nástroje](external-tools.md) | uv, Python, pripnuté balíky, vonkajšie stopy (skratka, plánovaná úloha, MCP registrácie). |
